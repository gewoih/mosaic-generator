# Непрерывная обводка силуэта (пункт 1 TODO)

## Проблема

Вокруг фигуры должно идти непрерывное кольцо в один-два ряда (opus vermiculatum).
Механизм укладки есть (`Tessellation.Advected` шаг 2), но контуры, вдоль которых он
кладёт ряды, рваные: силуэт чайки (~85 модулей обвода) разбит на 7 фрагментов, самый
длинный 30 модулей. По восьми фото — 10–16 контуров, длиннейший 23–40 модулей.

Причина: `ContourSet.Extract` берёт линию уровня силы края (`field.EdgeCells`,
марширующие квадраты, порог — процентиль от максимума). Там, где серое крыло чайки
совпало по тону с серо-голубым небом, перепада яркости нет — линия уровня обрывается.

## Что известно про данные

- `Tessellation.Advected` на момент раскладки имеет только `DirectionField` — яркостный
  `edge` и поле ориентаций. Цвета ещё нет: квантование идёт после раскладки.
- `DirectionField.Compute` уже сэмплит кадр (`SampleLuminance`), но оставляет только
  `Lab.L`. Полный цвет (`a`, `b`) в поле не доходит.
- Разрыв на чайке — совпадение по **тону**, но не по **цветности**: крыло серое, небо
  серо-голубое. Значит замкнуть контур можно, если добавить в разделение цвет.

## Решение

Строить силуэт не по линии уровня силы края, а по **границе связной области фигуры**.
Фигуру отделяем от фона по цвету и яркости относительно статистики периметра кадра
(рекомендованный вариант — минимальный, который реально закрывает чайку; полноценная
graph-cut сегментация — избыточна для инструмента на одного мастера).

### 1. `FigureMask` — новый класс, `Core/Grid/FigureMask.cs`

Маска фон/фигура на сетке поля (та же решётка `Width×Height`, что у `DirectionField`).

**Вход:** средний Lab каждой ячейки поля + существующий `edge`.

**Модель фона.** Взять Lab ячеек внешнего кольца кадра (полоса ~6 % узкой стороны).
Свернуть их в 1–3 кластера (k-means, k подбирается по разбросу — небо + вода на пейзаже
дают два). Порог принадлежности `τ` — из внутрикластерного разброса кольца
(медиана + `k`·MAD, клампится в разумные пределы по ΔE).

**Классификация ячейки.** Фон, если `min ΔE` до кластера фона `< τ`. Иначе — фигура.
Сильный край (`edge` выше уровня `ContourSet`) — всегда барьер, через него заливка фона
не течёт.

**Связность.** Залить фон внутрь от рамки по ячейкам «не-фигура и не-сильный-край».
Фигура = крупнейшая связная компонента незалитого. Морфологическое замыкание
(dilate→erode) радиусом ~1 модуль: перекрывает мелкие протечки в местах, где тон всё же
совпал и `τ` не сработал, и убирает точечные дыры. Залить внутренние дыры. Оставить
крупнейшую компоненту.

**Предохранитель (fallback).** Вернуть «маски нет», если:
- кольцо периметра неоднородно настолько, что `τ` поглощает почти весь кадр;
- фигура вырождена: > 85 % или < 3 % поля, либо заметно упирается во все четыре края.

Тогда `ContourSet` работает как сейчас. Ожидаемо сработает на `landscape`,
`landscape-2`, возможно `dolphin` — там сплошного силуэта нет, и это правильно.

### 2. `DirectionField` держит маску

`DirectionField.Compute` уже имеет `image` и `crop`. Расширить `SampleLuminance`, чтобы
сохранить средний Lab (три массива вместо `L`), построить `FigureMask` после `edge`,
сложить в поле: `internal FigureMask? Figure`.

Плюс: сигнатура `ContourSet.Extract(field, …)` не меняется, диагностический стенд
и `CourseGuidance` продолжают работать без правок.

### 3. `ContourSet.Extract` использует маску

- Маска есть и не вырождена: обвести её границу теми же марширующими квадратами (по
  маске 0/1 на уровне 0.5) — получается **один замкнутый полигон** на компоненту и на
  внутреннюю дыру. Это контур 0 (силуэт), гарантированно непрерывный.
- Существующий метод по линии уровня `edge` продолжает работать — для **внутренних**
  границ (раздел крыла и корпуса, плавник дельфина, горизонт). Полилинии, лежащие ближе
  `weld` к силуэту, отбрасываются как дубликат обводки. Остальные остаются.
- Сортировка как сейчас (длиннейший первым) — силуэт естественно оказывается первым.

### 4. Два ряда обводки — оба снаружи, в фон

Сейчас `Tessellation.Advected` шаг 2: `offset ∈ {−dAcross/2, +dAcross/2}` — один ряд
внутрь фигуры, один наружу.

Для контура-силуэта класть оба ряда со стороны фона: `offset ∈ {+dAcross/2,
+3·dAcross/2}` по внешней нормали. Направление обхода полигона маски известно (фон
снаружи), поэтому нормаль однозначна. Внутренние контуры (у них «снаружи» нет)
по-прежнему обкладываются с обеих сторон.

## Как проверить

Стенд `tools/MosaicGenerator.Diag`, все восемь фото, размеры 15×15 / 30×30 / 60×60:

1. **Длина силуэта.** Самый длинный контур сравним с обводом фигуры: для чайки 30×30 —
   порядка 80 модулей вместо нынешних 30. Печатать по каждому фото.
2. **Глазами** на 30×30 и 60×60 (`gull`, `gull-2`, `human`, `dolphin`): вокруг фигуры
   читается непрерывное кольцо.
3. **Fallback.** На `landscape`, `landscape-2` маска вырождается, контуры — как сейчас,
   без регресса.
4. **Без ухудшений** (по восьми фото): доля кусков по зонам, `merged`, `dominant`,
   счётчик причин обрыва курса, медиана длины курса под куском — не хуже прежних.

## Риски

- Пёстрый фон классифицируется неверно → ловится предохранителем, откат на старый метод.
- Два ряда обводки целиком в фоне утолщают ореол; на 15×15 это складывается с пунктом 2
  (бордюр уже съедает половину). Мерить долю кусков в контурных курсах на 15×15 — если
  растёт, для маленьких панно оставить один ряд.

## Итог (2026-09-03)

Сделано по плану. Отличия от плана по ходу работы:

- **Разбор седловой ячейки в `MarchingSquares`.** Бинарная маска 0/1 на диагональной границе даёт
  сплошные седловые ячейки (case 5/10). Прежний фиксированный разбор рвал кольцо на каждой
  ступеньке. Теперь разбор по значению центра ячейки, с ничьёй (все четыре угла = уровню) в пользу
  связности области выше уровня. Затрагивает и путь по линии уровня — там седло на гладком поле
  редкость, разбор по центру корректнее прежнего.
- **`ChainExact` вместо `Chain` для маски.** Обобщённая склейка по близости (`weld` ≈ 2–6 ячеек)
  на плоском участке границы замыкает кольцо само на себя, разбивая его пополам. Для маски, где
  соседние сегменты делят вершину точно, склейка по точному совпадению вершин; путь по линии
  уровня остаётся на `Chain`.
- **Число рядов силуэта зависит от размера панно** (2 от 30 см, 1 меньше). На 15×15 два ряда
  целиком в фоне давали контурным курсам 34–38 % кусков.
