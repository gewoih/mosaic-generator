# Сверка палитры с фотографией веера ArtWorker (2026-09-07)

Палитра — 152 артикула, HEX однажды сняты с фотографии физического веера образцов. Проверка:
снять цвета с той же фотографии заново, машинно, и сравнить с тем, что лежит в
`Web/Data/palettes/artworker-smalt.json`.

## Как мерилось

Веер снят одним кадром 2000×1273: 8 столбцов («Line 1»…«Line 8»), внутри столбца плашки сложены
в вертикальные стопки с промежутками. Порядок артикулов в JSON совпадает с порядком на фото
один в один — это и позволило сопоставить замер с записью без распознавания подписей.

1. Маска «не бумага» по отклонению от белого (`255 − min(RGB) > 12` или `max−min > 12`),
   замыкание 3×3 — стопки выделяются как связные прогоны, поэтому границы стопок берутся
   из маски, а плашки внутри стопки — равным делением (высота плашки в стопке постоянна).
   Две стопки с внутренним разрывом (`GR80` в Line 7, `GR25` в Line 8) и две стопки, где
   белые плашки сливаются с бумагой (`TJ01…SX42`, `GX02…SS15`), размечены по кропам глазами.
2. Из каждой плашки берётся медиана центральной полосы — 25–75 % по высоте, средние 50 %
   по ширине. Медиана, а не среднее: смальта бликует, у части плашек блик занимает четверть
   поверхности.
3. Контроль — наложение рамок замера на исходник и сетка «кроп плашки | цвет из JSON»
   на все 152 позиции. **Судья здесь тоже картинка, а не dE:** два самых больших расхождения
   по числу (`DK15` 16,7 и `SK08` 4,7) оказались артефактом блика, а не ошибкой в JSON.

## Что нашлось

Средний dE76 между JSON и замером — 2,02; 121 значение из 152 внутри dE76 3, то есть внутри
погрешности самой фотографии. Исправлено шесть:

| Артикул | Было | Стало | Почему |
|---|---|---|---|
| `SQ01` | `#94B4CE` | `#6F94BE` | Значение снято с белого блика. На фото плашка — средний стальной синий, заметно темнее соседнего `FR01`; dE76 от замера 15–22 при обоих способах оценки. |
| `DK14` | `#ED7B66` | `#EE5B3F` | Было недосыщено: на веере рядом с `DK01` это яркий томатно-красный, а не лососевый. |
| `ST06` | `#354649` | `#2A3A40` | Осветлено: на фото плашка темнее соседнего `ST02`, почти чёрная с сине-зелёным отливом. |
| `SE15` | `#B5DB8D` | `#A7D37C` | Осветлено: на веере это средний яблочно-зелёный, а не пастель. |
| `SP15` | `#80B7DA` | `#72ABD2` | Осветлено. |
| `SX22` | `#C4834A` | `#BC7838` | Осветлено. |

Не менялись, хотя по числу выглядели подозрительно: `DK15` и `SK08` (блик покрывает большу́ю
часть плашки, замер завышен), `DK07` (в JSON правильно приравнен к `DK15` — на веере это один
цвет), `TQ06`, `DK03`, `FA01` (расхождение внутри шума кадра).

## Имена

Имена перегенерированы целиком по L\*C\*h — прежние противоречили сами себе («Бледный насыщенный
жёлтый» при C\* 80) и местами врали про тон (`DK02` `#F0D622` числился «жёлто-зелёным»,
`SX17` `#634D3A` — «тёмным жёлтым»). Имя — только подсказка в таблице расхода; единственный
достоверный идентификатор — артикул, и одинаковые имена у близких артикулов допустимы.

Правило (L, C, H — CIE L\*C\*h из sRGB, D65):

- **Ахроматика** при C < 5 (кроме L ≥ 93 и C ≥ 3 — те идут в хроматику):
  белый ≥ 93, светло-серый ≥ 78, серый ≥ 55, тёмно-серый ≥ 25, ниже — графитовый.
- **Светлота:** «очень светлый» ≥ 88; «светлый» ≥ 68 (≥ 60 при C ≥ 55); без слова; «тёмный»
  < 45 (< 38 при C ≥ 40); «очень тёмный» < 28 (< 24 при C ≥ 40). Сдвиг порогов у насыщенных
  нужен потому, что у чистого красного максимум L\* около 53 — иначе алая смальта называется
  «тёмной».
- **Насыщенность:** «приглушённый» при C < 16, «насыщенный» при C ≥ 45.
- **Тон по H:** 345–15 розовый/малиновый (по светлоте) · 15–38 красный (C ≥ 45) или
  терракотовый · 38–50 коричневый (L < 48 и C < 40) или оранжевый · 50–80 оранжевый/янтарный
  (C ≥ 55, граница по H 65), иначе коричневый (L < 48 и C < 40) или охристый · 80–100
  коричневый (L < 45 и C < 25) или жёлтый · 100–125 оливковый (L < 70 и C < 45) или лимонный ·
  125–160 зелёный · 160–200 изумрудный · 200–235 бирюзовый · 235–265 синий (L < 35) или
  голубой · 265–285 синий · 285–320 сине-фиолетовый (C ≥ 25) или сиреневый · 320–345 сиреневый.
- **Пастель:** при L ≥ 88 и C < 20 тон 15–50 называется розовым, 50–100 — кремовым, слово
  «приглушённый» опускается.

## Что стало с картонами

Прогон всех `samples/`, 21×21, модуль 10 мм, 12 цветов. Геометрия раскладки не сдвинулась
нигде (525 тессер, те же проценты узких и неколибельных); менялся только подбор цвета.
Средний ΔE по фото: 5 без изменений, три лучше (`poppy` 24,9 → 22,6, `landscape` 8,8 → 8,4,
`wave` 14,8 → 14,7), два хуже (`gull` 8,1 → 10,1, `cat-dusk` 14,8 → 15,2).

- **`poppy` — видимое улучшение**, ради которого правка и делалась: лепестки были блёклым
  лососевым (`DK14` в старом значении), стали алыми. Это и есть настоящий мак.
- **`gull` — видимое ухудшение.** Небо набиралось двумя оттенками, светлым `SQ01` и лавандовым
  `FO05`; после правки `SQ01` потемнел, из неба выпал и небо стало однородным. Прогон на 14
  цветах даёт то же самое — дело не в редукции, подходящего светлого голубого в веере просто
  нет. Старый картон обещал градиент, которого материал не даст: набранное панно вышло бы
  темнее и площе картона. Здесь картон стал беднее, но перестал врать.

**База ΔE сброшена:** числа до 2026-09-07 с новыми не сравнивать.
