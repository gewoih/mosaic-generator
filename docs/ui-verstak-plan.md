# UI: верстак вместо двух простыней

> Сделано 2026-09-06. По ходу вскрыты два пункта — TODO 16 (читалка сетки считает
> квадратным куском) и TODO 17 (легенда налезает сама на себя).

## Проблема

Веб — одностраничная форма → страница результата. Обе устроены линейно и захламлены.

- **Index**: фото, кроп, стена параметров. Три контрола, которые мастер реально крутит
  (размер панно, откус, максимум цветов), лежат вперемешку с фиксированными (палитра,
  цена ₽/кг, запас %). У каждого поля абзац пояснения.
- **Result**: сводка из 7 строк (`<dl>`), три абзаца `summary__note`, полный дубль формы
  параметров инлайном, три картинки составлены друг на друга с равным весом, таблица
  расхода с ещё двумя абзацами.
- Рабочий цикл — 5–7 пересборок на одном фото, крутятся размер / откус / цвета. Сейчас
  между мастером и формой — гигантский картон, сводка и проза; поменять одно число и
  пересобрать = долгий скролл туда-обратно.

## Что делаем (подход A из брейншторма)

Обе страницы приходят к одному макету-«верстаку»: слева липкая рельса управления,
справа сцена с картоном. Полноэкранный POST и PRG сохраняются, SPA не вводим.
Контроллер, модели и маршруты не трогаем — только вьюхи, CSS, немного JS.

### 1. Макет `.workbench`

CSS-грид: две колонки на широком экране, одна на узком (<900px, рельса сверху).
Рельса ~22rem; на Result `position: sticky` — не уезжает при скролле и пересборке.
На Index сцена до генерации показывает подсказку.

Мачта: убрать устаревшее «· прямоугольная укладка» (теперь андаменто); засечный вордмарк.

### 2. Рельса — `_Controls.cshtml` (заменяет `_Parameters.cshtml`)

Сверху вниз:

1. Кроп — компактный (до ~14rem). На Result в `<details>` (свёрнут), на Index открыт
   после выбора фото.
2. Размер панно — ширина × высота в ряд, под ними компактная строка-читалка
   (сетка N×M, поля) без тяжёлой пунктирной рамки.
3. Откус — плотные чипы-радио вместо крупных карточек.
4. Максимум цветов — числовое поле, хинт в одну строку.
5. Кнопка «Сгенерировать» / «Пересобрать макет».
6. `<details>` «Материал» (свёрнут, состояние запоминается): палитра, цена ₽/кг,
   запас %.

Проза-аргументация → короткие `<small>` в строку или `title`.

### 3. Сцена (Result)

- Компактная сводка одной строкой над картоном; детали (поля, запас, цена, «свёрнуто
  N оттенков») — в `<details>` «Подробности». Предупреждения остаются короткой плашкой.
- Картон крупно во всю ширину сцены; тонкая полоса под ним: размеры px/dpi, «Скачать
  PNG», строка про масштаб и линейку 100 мм.
- Вкладки `[Картон] [Легенда] [Схема]` вместо трёх составленных картинок. По умолчанию
  Картон. У каждой вкладки своя кнопка скачивания.

### 4. Таблица расхода

Во всю ширину под верстаком. Колонки-данные (модули, площадь, масса, стоимость)
остаются — это спецификация под заказ. Два абзаца пояснений → одна строка. Чекбоксы
«Держать» остаются (часть цикла: закрепил оттенок → пересобрал).

### 5. Вид

Тёплая «бумажная» палитра остаётся (терракота `#7a3b2e`). Типографическая шкала,
`accent-color` для радио/чекбоксов, tabular-nums на числах, состояния кнопок и фокуса,
засечный вордмарк. Тёмная тема не вводится.

### 6. Память — новый `wwwroot/js/ui.js`

- Состояние `<details>` «Материал» и активная вкладка.
- На Index при загрузке подставляются последние палитра / цена / запас / откус
  (сейчас всегда серверные дефолты).
