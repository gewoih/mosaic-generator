## 3. Шаг 2 — п. 13: редуктор не плодит рассинхрон

### 3.1. Правка

`PaletteReducer.Reduce`, цикл `foreach (int cell in orphans)` (`PaletteReducer.cs:133`):
вместо поштучного `candidateIndices[Quantizer.NearestIndex(cellLab[cell], candidateLab)]`
— копим всех сирот раунда и назначаем каждой артикул по энергии

```
cost(cell, k) = Match²(cell, pal_k)
              + λ · Σ_j w_ij · Match²(pal_k, pal_{выбор_j}) / Σ_j w_ij
```

где соседи `j` — по `CellNeighbourhood`, `выбор_j` — уже осевший артикул соседа
(в т.ч. сирота этого же раунда, решённая раньше), `w_ij = ColorDistance.NeighbourWeight`,
`λ = CoherentMap.NeighbourWeight` (0,5). Та же формула и та же мера `Match`, что в
`CoherentMap.Settle` — не заводим второй закон согласования.

Сирот решаем не строго по одной: порядок обхода — по возрастанию числа уже осевших
соседей (сначала те, у кого контекст беднее меняется), тай-брейк по индексу ячейки,
для воспроизводимости. Достаточно одного прохода по списку сирот раунда — редукция и так
итеративна по раундам.

### 3.2. Прокладка `CellNeighbourhood`

Сейчас в `Reduce` идёт `tesserae` ради `BuildAdjacency` (компактность кластера при
выборе жертвы). Добавляем параметр `CellNeighbourhood? neighbourhood` — в
`MosaicGenerationService` она уже построена (`neighbourhood`, строка ~86) и передаётся
в оба `CoherentMap.Settle`. Overload `PaletteReducer.Reduce(..., Palette, int)` для
тестов — строит свою через `CellNeighbourhood.Build(tesserae, ...)` или оставляет
поштучный путь, если `tesserae`/`neighbourhood` нет (обратная совместимость).

## 8. Что сделано на шаге 2 (2026-09-06)

`PaletteReducer.Reduce` получил параметр `CellNeighbourhood? neighbourhood`. Когда он
передан (`MosaicGenerationService` отдаёт ту же `neighbourhood`, что в оба `CoherentMap`),
осиротевшие ячейки раунда раздаются не поштучным `Quantizer.NearestIndex`, а
`HandOutOrphans`: посев ближайшим, затем один проход релаксации — сироты с бо́льшим числом
уже осевших соседей первыми — по энергии `Match²(cell, k) + λ·Σ w·Match²(k, выбор соседа)/Σw`,
`λ = CoherentMap.NeighbourWeight`. Та же формула, что в `CoherentMap`.
