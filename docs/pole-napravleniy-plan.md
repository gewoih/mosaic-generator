# Поле направлений: нормировка когерентности по перцентилю кадра

Закрывает бывший пункт 1 TODO («Поле направлений почти мертво: фотография ведёт 1–4 % панно»).
Сделано 2026-09-04.

## Проблема

Андаменто должно идти от структуры фотографии. Стенд `tools/MosaicGenerator.Diag` по восьми
фото из `samples/` показывал:

- «поле ведёт фотография на N %»: **1 %** (dolphin), **1–2 %** (gull), **2–4 %** (gull-3);
- когерентность тензора: `p50 = p75 = 0,080` у всех восьми фото и всех трёх размеров, без
  исключений. Плато ровно на 0,080 — не свойство фотографий, а константа из кода.

Раскладку в фонах вело диффузное эхо от рамки панно, а не сюжет — корень «сумасшедшей
кладки» (opus palladianum) во всех восьми фонах.

## Причина (`Core/Grid/DirectionField.cs`)

1. **Нормировка на глобальный максимум кадра.** В `Compute` при построении `vx/vy` делитель
   `maxCoherence` — максимум сырой когерентности тензора по всему кадру. Один блик или один
   жёсткий контур задавал делитель, и `weight = min(1, length / (maxCoherence · 0,7))` уводил
   вектор направления почти каждой ячейки в ~0.
2. **Штамп `hint = 0,08`.** `SeedBlankCells` ставил `const double hint = 0.08` в каждую
   «пустую» ячейку (длина вектора < 0,05). Так как после шага 1 почти все ячейки были
   пустыми, диффузия усредняла 0,08 повсюду — отсюда ровно 0,080 в p50/p75.

## Что сделано

### 1. Перцентильная нормировка вектора направления

`DirectionField.Compute`: когерентность всех ячеек собирается в массив, делитель —
`confidenceScale = max(1e-9, Percentile(coherence, 0.95))` (переиспользован
`ContourSet.Percentile`, переведён в `internal`). `weight = min(1, length / confidenceScale)`,
без прежнего множителя 0,7. Один сильный градиент больше не задаёт шкалу всему кадру.

**`edge` не тронут.** `edge[k] = min(1, length / maxCoherence)` кормит `ContourSet.LevelFor`
с зашитыми абсолютными порогами (`strong < 0.15 → 0`, `max(0.12, strong·0.42)`) и через него
`FigureMask` (силуэт-кольцо, непрерывная обводка). Менять его нормировку — отдельный риск для
детекции формы, в этот пункт не входит. `maxCoherence` остался только для `edge`.

### 2. Семя

`SeedBlankCells`: `hint` снижен 0,08 → **0,03**, ниже доверия, которое настоящие края теперь
несут (перцентильная шкала, ≈1). Плато p50/p75 разрушено.

### 3. Порог `CourseGuidance.FullConfidence` — перепроверен, оставлен 0,35

Свип по восьми фото на исправленном сигнале (0,18 / 0,25 / 0,35 / 0,5, размеры 15×15 и 30×30):

| FullConfidence | «поле ведёт» | курсы |
|---|---|---|
| 0,18 | 25–69 % | рассыпаются (human 55–60 % курсов < 3 кусков) |
| 0,25 | 15–52 % | чуть короче 0,35, филлеры те же |
| **0,35** | **12–34 %** | доля коротких курсов минимальна |
| 0,50 | 9–18 % | длиннее всех, но фото почти не ведёт |

0,35 сидит на колене: цель пункта (голос фотографии) достигнута самой нормировкой, а
приоритет №1 проекта — целостность геометрии набора. Комментарий `CourseGuidance.cs`
переписан под новый замер, константа не тронута, память `porog-doveriya-tenzoru` верна.

## Результат (стенд, восемь фото)

- «поле ведёт фотография»: **12–34 %** (было 1–4 %).
- когерентность тензора: p50 **0,030–0,259**, p75 **0,088–0,426** — различается между фото,
  больше не константа. На плоском небе (gull) p50 ~0,03 — верно, структуры там нет.
- филлеры / доля коротких курсов — не хуже прежних, местами лучше (landscape-2, gull-2).
  Обрывы курса (99 % по расстоянию) — отдельный дефект, пункт 1 TODO, мерить по этому полю.
